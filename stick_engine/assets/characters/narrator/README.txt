NARRATOR — detective host (70 years old)
========================================

A mysterious, eccentric detective with a dark fedora, weathered gray hair and curled mustache, an icy blue left eye and amber right eye, a dark teal trench coat, and a magnifying glass.

Install this folder at:
  stick_engine/assets/characters/narrator/

This character uses the same 360x620 hierarchical rig and action set as stickman. Its colored PNG parts have `embedded_color: true`; use the included renderer.py and renderer_gpu.py so the blue/amber eyes, skin, clothing, and accessories keep their colors. The included storyboard.py selects the narrator type automatically when the asset is installed.
